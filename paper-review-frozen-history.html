实时超采样靠跨帧累积抖动样本。这篇论文展示了一个反直觉的结果： 当配准足够准确时，时序一致性损失会反过来奖励“复制历史”—— 网络停止吸收新样本，静态画面变得异常稳定，而像素方差与时序 PSNR 反而把这种退化读成“更稳、更好”。

结论速览：指标为何会奖励退化

一页速览。五个结论，按“机制 → 证据 → 工程 → 边界”排序。

  1. 时序损失并不天然鼓励累积。配准准确时，把上一帧输出 warp 过来几乎不付时序代价； 这个代价叫 copy cost，等于参考自身重投影后的变化。参考越“静止”，复制历史在时序项上越便宜。
  2. λT 一大，网络就停止累积。在 ×4 的受控分析网络（192 通道）上，λT=0.25 时，图中裁块的 α 中位数跌到 3.9×10⁻⁶；Table S2 全数据的中位数是 3.2×10⁻⁵，两者都低于 10⁻⁴。静态 PSNR 掉 0.86 dB； 但静态像素标准差同时下降，时序 PSNR 反而上升。
  3. 四类配准错误会掩盖这个故障。运动矢量含抖动、低分/高分晶格共用运动场、深度带抖动、 skip 路径未配准——它们抬高 copy cost，让“冻结”看起来更有吸引力。修正后 QRISP 上 ×2/×3/×4 分别提升 0.48 / 0.34 / 0.62 dB。
  4. 方法本身极简。归一化累积器 S/N + 小 λT=0.05 + 普通卷积， ×4 的 1080p 单帧在 H200 上为 0.332–2.032 ms（普通卷积），最轻的 shift-MLP 64×6 为 0.201 ms / 0.17 M 参数。
  5. 医学 DVR 的适用边界。全部验证在游戏资产上；半透明体素会破坏运动矢量， 无抖动输入会让模型失效（零样本 25.8 dB，低于双三次 33.2 dB）。它更适合作为方法学参考与配准清单， 而不是可直接部署的医学 SR。

01

背景：一帧只有 1/16 的样本，因此需要跨帧累积

实时渲染的帧预算由着色、几何与后处理共同占用。超采样把“分辨率”换成“时间”：这一帧少算一点，用过去几帧补回来。

以 ×4 为例：输出 1920×1080，内部只渲染 480×270。一个低分辨率像素要负责 16 个输出像素。仅靠空间插值无法恢复边缘与细纹理； 实时渲染的解法是让相机每帧做亚像素抖动（jitter），使每帧的采样点落在不同的子像素位置， 再把过去几帧的样本按运动矢量对齐、累积起来。

这里要区分两套坐标：格子是输出像素，点是抖动相位。在 ×4 的规则网格里，16 个相位的位置恰好与 16 个输出像素的中心重合，所以两张图看起来一样；但语义不同——相位是“这一帧从哪里采样”，输出像素是“重建结果写到哪里”。每帧的 1 个样本服务整块 16 个输出像素，而不是只更新点所在的那一格。

静态相机是这件事最纯粹的场合：画面不动，但抖动仍在继续，每个新样本都应该带来新的边缘信息。 一个已经“稳定”的估计，可能只是停止变化，而不是停止改进。论文要问的正是： 训练时的时序一致性损失，会让网络继续累积，还是让它提前停止累积？

学习式超采样把“混合”交给网络

经典 TAA/TAAU 用手写的指数平均和邻域 clamp 来混合历史。学习式方法则把当前 LR 颜色、深度、 运动矢量、历史帧一起喂给网络，让网络自行分配当前帧与历史的权重。为了抑制闪烁， 训练时通常再加一项时序一致性损失：让输出帧间的变化，去匹配参考帧间的变化。

这项损失的权重 λT 一直是手调的。论文的切入点很小：如果配准是准的，参考帧重投影后几乎不变， 那么“复制上一帧输出”在时序项上几乎不付代价。网络完全可以在重建项尚可的情况下， 选择不再吸收新样本。作者把这种现象叫 frozen history。

一个先验 静态画面越“稳”，不一定越接近真值。参考帧自己也在动——噪声、抖动、亚像素细节—— 冻结输出把参考的变化也一并抹掉了。问题是：指标能不能分辨“收敛”与“停止累积”？
02

方法：把“累积”写成一个可观测的比值

论文没有发明新模块。它把 TAAU 式的加权累积写成 S/N，让网络预测三个量，并监测 α。

在输出晶格上，维护两个缓冲：加权颜色和 St 与累积权重 Nt。网络在每个输出像素上预测候选颜色 ĉt、可靠性 rt∈(0,1)、 保留率 ρt∈(0,1)。新样本的权重 wt = k(dt)·rt，其中 k 是到像素中心的距离核。

式 1 · 归一化累积 St = ρt · vt · Rt[St−1] + wt · ĉt
Nt = ρt · vt · Rt[Nt−1] + wt
ŷt = St / Nt Rt 是重投影，vt 是历史有效性掩码。 关键在分母：同一个可靠性，在历史权重很大时只能带来很小的更新；历史被 disocclusion 清空时， 新候选立刻占满输出。S 与 N 同比例缩放可以把累积权重封顶到 Nmax，不改变输出。
式 2 · 新样本占比 αt = wt / Nt   →   ŷt ≈ αt · ĉt + (1 − αt) · Rt[ŷt−1] 在历史有效、空间常数、0<ρ<1 的稳态下，N = w/(1−ρ)， α = 1−ρ，累积退化为指数平均。α 是本文诊断“冻结”的核心可观测量： 它不是训练loss，而是部署时能直接记录的样本吸收率。

注意：Rt[S]/Rt[N] 一般不等于 Rt[S/N]，所以 α 只表示“新候选的摄入比例”， 不是严格意义上的混合系数。但在历史权重空间变化缓慢时，上面的近似足够解释行为。 论文在 QRISP 上把这种归一化累积与“网络直接预测 blend 权重”对比： PSNR 几乎一样（29.74 vs 29.71 dB），但静态像素标准差从 0.53 降到 0.43。 也就是说，归一化带来的是稳定性，而不是精度。

训练目标：让输出的变化去匹配参考的变化

式 3 · 训练损失 L = Σt ‖ŷt − yt‖22 + λT Σt ‖Δŷt − Δyt‖1,    Δxt = xt − Rt[xt−1] 时序项只统计有效像素，每个 clip 的前两帧不参与训练（重建项与时序项都跳过）。两个导数用同一个重投影， 所以它们的匹配程度完全取决于配准是否正确。论文推荐 λT=0.05： 在 ×4 的 45k 分析运行里，它把静态像素标准差从 0.77 降到 0.43，代价是静态 PSNR −0.19 dB。

03

机制：copy cost，为什么“复制历史”在时序项上几乎免费

这是全文的关键推导。它不需要网络，只需要参考帧、重投影和一条假设：冻结输出。

设输出误差 et = ŷt − yt。 如果网络完全冻结，ŷt = Rt[ŷt−1]， 那么它的时序导数 Δŷt = 0。代入式 3 的时序项，惩罚只剩下参考自己的变化：

式 6 · 冻结输出的时序代价 ‖Δŷt − Δyt‖1 = ‖Δyt‖1 = ‖yt − Rt[yt−1]‖1 右边这一项就是 copy cost：参考帧经过同一个重投影之后，还剩多少变化。 静态相机、准确配准、低噪声参考 → 这一项很小，冻结在时序项上几乎“免费”。 它和冻结保留了多少重建误差无关。

把冻结输出代回误差定义，可以得到一个上界：

误差上界 ‖et‖ ≤ ‖Rt[et−1]‖ + ‖Rt[yt−1] − yt‖ 第一项是旧误差被重投影后的残留，第二项是 copy cost。两者都不奖励“新信息”—— 只要 copy cost 足够小，冻结输出在时序项上就接近最优；这与旧误差多大无关。

没有网络也能测：oracle 实验

作者构建了一个不训练模型的 oracle：把 QRISP 的参考帧按 k 步链式重投影，比较“正确配准”与 “带抖动运动矢量”两种 warp。×4 下，单帧配准 copy 在测试帧上达到 35.71 dB， 带抖动 warp 只有 25.45 dB；在静态相机帧上，配准 copy 达到 48.74 dB， 错配 copy 停在 24–27 dB。最长静止段上，配准 copy 连续四次重投影仍高于 58 dB。 对应的静态 L1 copy cost 是 3.2×10⁻⁴ vs 3.76×10⁻²，相差 118×。

这解释了为什么故障会被“藏起来”：如果运动矢量本身带抖动，静态参考也会被平移， copy cost 被抬高，冻结不再便宜，网络就没有动机停止累积。反过来，一旦把配准修对， 时序损失才开始“奖励”冻结。

01 运动矢量包含相机抖动 copy cost ×118

QRISP 提供的是抖动投影之间的运动 m̃t。如果直接用它 warp 输出历史， 静态内容也会被平移，copy cost 被抬高。论文故意用未补偿的 shipped field 做 J 实验： 静态 L1 copy cost 3.76×10⁻²，而正确配准是 3.2×10⁻⁴。

注意：QRISP 自己的流水线会去掉这个抖动位移（TAA 惯例）。论文不是说 QRISP 有 bug， 而是用它来隔离“运动约定”对 copy cost 的影响。

修正：输出历史 warp 用 mt；样本侧用 m̃t。两套晶格的运动场不可混用。

02 低分/高分晶格共用同一运动场 28.35 vs 26.52 dB

把抖动从所有 warp 里都去掉，会制造另一个错误：mt 不含输入晶格的位移。 用 m̃t 把上一帧低分辨率渲染带过来是 28.35 dB； 用 mt 只有 26.52 dB；平均绝对残差从 0.0357 涨到 0.0433（+21%）。

修正：输出侧用 mt，样本侧（含 LR 循环特征、skip）用 m̃t = mt + (ot−ot−1)。

03 深度带抖动 ~10³× / 训练发散

抖动深度每帧采到不同表面点，深度变化会触发去遮挡测试或运动膨胀，即使相机静止。 School 静止段上，抖动深度的平均重投影变化大约是无抖动深度的 10³ 倍。

留一消融里，去掉无抖动深度后 seed-0 在约 11k 次迭代发散（非有限值）； seed-1 相对自己的对照掉 0.14 dB。

修正：历史测试、重投影有效性、去遮挡都用无抖动深度；抖动只用于颜色采样。

04 skip 路径未配准 / 相位符号错 +0.86–1.53 dB

双三次 skip 必须把当前样本放在 xt(q)，而不是输入像素中心。 在 5 帧运动的 SeaPort 上，不训练网络、只修这个偏移就能涨 0.86–1.53 dB。

相位若用 +jty 会镜像垂直偏移。×4 时 16 个抖相位全部选错行， 平均位移 1.80 个输出像素。School 静止段：正确相位 34.19 dB，镜像相位 29.78 dB， 抖动输入直接双三次 28.38 dB。

修正：skip 采样位置 xt(q)；相位符号统一成 ot=(jx, −jy)。

训练为何会放大配准错误

最反直觉的一点：这些错误在 λT=0 时几乎看不出来。完整配准 29.75 dB， 原始约定 29.72 dB，只差 0.03 dB；单个组件的留一消融也只改 0.03–0.12 dB。 训练会通过学到的补偿部分抵消几何错误，重建质量指标因此失去诊断力。

真正的诊断信号是“时序权重响应”：在正确配准下，增大 λT 应该让 PSNR 下降、α 塌缩； 如果增大 λT 反而让 PSNR 上升或静态变化不变，说明配准有问题，冻结被藏住了。 论文称之为“配准反转了时序权重对 PSNR 的影响”（registration reverses the temporal weight’s effect on PSNR）。

自检顺序

先别调 λT。先逐条核对：① 输出 warp 是否含抖动；② 两套晶格是否各用各的运动场； ③ 深度是否去抖动；④ skip 位置与相位符号是否正确。四项全过，再谈权重。

一个细节 论文的 R 与 J 是整条流水线的对照：R 同时修正四类错误，J 同时保留四类错误。 所以 Table 1 的差异不能拆给单个错误；单个错误的量级要看留一消融和 oracle。
05

架构与训练：极简架构为何足够

这篇论文在架构上的新意有限，但它的受控比较给出了一条明确的工程结论：先把配准与学习率处理正确，再讨论模块。

主干是 8 个残差块，每块两个 3×3 卷积 + GELU，无归一化，学习到的通道缩放初始化为 0.1。 第一层 3×3 卷积由抖动调制；三个 1×1 头输出候选颜色、可靠性、保留率，再经 sub-pixel rearrange 搬到输出晶格。×2/×3 用 192 通道，×4 用 256 通道。颜色头把残差加到一个双三次 skip 上， skip 必须在配准后的样本位置采样。累积器 Nmax=16， 距离核是高斯的，学习到的宽度接近平坦；另有 state guard，在颜色/特征越界时重置像素块， 防止长序列偶发发散。

补充材料 S13 比较了若干更复杂的模块：U-Net、部分卷积、star block、倒残差、深度可分离、 池化、线性注意力。结论不是“普通卷积永远最好”，而是：在作者的受控设置里，复杂模块大多没有稳定收益。 U-Net 从 +0.01 到 −0.27 dB；部分卷积、star block、带 depthwise 的倒残差在宽网络档掉 0.29–0.56 dB；小网络档的 ECB 重参数化能涨 0.24 dB，但普通卷积把学习率调高也能涨 0.23 dB， 两者叠加只剩 0.13 dB。换句话说，学习率本身就是架构比较的一部分。

训练配方

30 帧 clip · 66×66 LR crop · batch 8 · AdamW（β₁=0.9, β₂=0.99, wd=10⁻⁴）· one-cycle · 峰值 lr 6×10⁻⁴ · λT=0.05 · 前两帧不参与训练（含重建项）。45k 是分析模型，最终 ×2/×3 100k、×4 200k。

还有一个容易忽略的细节：clip 长度本身会影响 α。把训练 clip 从 30 帧缩到 16 帧， PSNR 掉 0.14 dB，静态 α 中位数从 2.3×10⁻³ 降到 8.3×10⁻⁴。更短的 clip 让网络见不到 “长时间保留历史”的后果，反而更容易压低样本吸收。论文选择 30 帧训练，并非随意。

部署 论文的计时全部是 H200、batch 1、1080p、融合 kernel + 单个 CUDA graph、bf16 主干 + fp32 累积， 且不含渲染。消费级 GPU 的完整渲染器 profile 是作者明确留下的未来工作。

三个边界实验

Arm Bistro 零样本。QRISP 训练的 ×2 模型不重新训练，直接迁移到 Arm 的 100 帧 Unreal 抓帧 （92 帧计分，period-32 抖动、1/8 像素网格）。结果 31.62 dB，比两个经典时序上采样器高 4.4–4.5 dB；报告的主要指标都更好。匹配的 45k 对照里，带历史的 31.07 dB，单帧 26.64 dB， 差 4.43 dB——这个差值直接量化了“历史”本身的价值。

STSS 无抖动。这是反面证据。STSS 的输入不抖动，时序损失失去了“互补样本”这个前提。 重新训练后 λT=0 的均值 33.48 dB，高于 STSSNet 的 32.89（论文 §7.3 的 STSS 协议：偶数帧、8-bit）； λT=0.25 时均值掉 1.93 dB。按 §5.4 的全帧协议，Arena 单场景从 34.16 掉到 30.46（−3.70 dB）—— 两套协议不可直接比较（1.93 dB vs 3.70 dB），但方向一致。在无抖动数据上，时序损失是净损失。 这条实验把“配准正确”这个条件又收紧了一步：不仅要配准对，还要有真正的互补样本。

历史消融。把颜色历史、累积器、循环特征一起去掉，×2 掉 1.65 dB，×4 掉 2.02 dB； 静态 STD 从 0.11 升到 1.09（×2），从 0.44 升到 1.74（×4）。历史是主要贡献，而非附带项。 归一化与直接 blend 的 PSNR 几乎一样，但前者静态 STD 0.43 vs 0.53； 短 clip（16 帧）PSNR 掉 0.14 dB，α 反而更低——更短的历史让网络更不敢吸收新样本。

引用注意

“2.03 ms”对应的是 256×8 / 30.04 dB，时延是 QRISP-L 的 2.91×。 “比 QRISP-L 快 25%、高 0.07 dB”对应的是 96×4 / 0.524 ms / 29.49 dB。 “快 71%、只低 0.10 dB”对应 shift-MLP 64×6 / 0.201 ms / 29.32 dB。 三个配置不要混着引用。所有数字都是 H200、1080p、不含渲染。

07

批判性阅读：已证明与未证明的边界

论文的边界与结论同样重要。下面把“已有证据支持”和“尚未证明”分开列。

已有证据支持

  • 因果链较完整。从式 6 的 copy cost，到无网络 oracle，到受控训练，再到三网络族/两尺度复现，最后到真实 benchmark。每一步都能独立复核。
  • oracle 设计清晰。用参考帧链式重投影隔离运动场，不依赖训练；118× 的差距是可直接复算的。
  • 对指标的批评有数据支撑。PSNR↓、静态 STD↓、tPSNR↑、JOD↓ 同时出现，不是“感觉指标不对”。
  • 工程贡献可迁移。四类配准错误与两套晶格的公式，和网络结构无关；任何 TAAU/神经超采样管线都能逐条核对。
  • 代码 MIT 开源。训练、推理、评估、数据集转换、融合 kernel 都有；权重未随仓库发布。

尚未证明

  • 未在医学/体渲染域验证。全部在游戏资产上；半透明体素、传递函数分层、无 MV 的粒子/sprite 都没有覆盖。
  • 消费级 GPU 未测。H200 的 0.201–2.032 ms 不能线性外推到 RTX 4060；完整渲染器 profile 是作者留下的未来工作。
  • 连续尺度不支持。只有 ×2/×3/×4 三个离散档；没有任意倍数。
  • 机制网格单种子。15k 种子对只测了重复性，不是每个机制设置都多种子。
  • 主表不是同容量对比。容量最大的模型为 256 通道，QRISP-L 更小；主表比的是完整系统，不是同容量架构。
  • 输入分布脆弱。无抖动输入下，QRISP 模型零样本 25.8 dB，低于双三次 33.2 dB；迁移取决于抖动分布。

论文没有说的三件事

  • “时序损失是坏的”。论文只说：在配准正确、参考变化小、λT 大的条件下，它会抑制累积。 在 J 约定下，同样的损失甚至略微提升 PSNR；在运动帧上，0.25 的代价也只有 0.24 dB。条件不成立时，它未必有害。
  • “λT=0.05 是通用最优”。0.05 是在 QRISP、这个主干、这套配准约定下测出来的折中。 换配准、换数据分布、换损失范数，都要重新扫。论文自己说：“改变配准约定或数据分布后必须重新考虑。”
  • “冻结总是坏事”。如果历史确实比新候选好，复制历史是理性的。论文判定“有害冻结”的条件是： 复制增加的同时，准确率/感知质量下降。单独看 copy fraction 高，不足以判定为有害。

如果要把这套方法搬到医学 DVR

迁移时最关键的是输入接口。论文的输入是 {抖动 LR 颜色, 深度, 运动矢量}， 而 DVR 恰好天然拥有深度和逐像素运动（相机矩阵解析可得），抖动也可以由应用层注入； 辅助数据几乎没有额外 pass 成本。从接口上看，它比纯图像医学 SR 更匹配 DVR，但半透明场景仍需重新定义 MV。

但有两个硬问题：① 半透明。DVR 的透射/半透明层会让“这个像素属于哪个表面”变得模糊， 运动矢量不再唯一；论文的 sprite 案例已经表明，无 MV 的 sprite 会被历史涂抹。 ② 域偏移。游戏资产的噪声、边缘、材质统计和 CT/MR 体渲染差别很大； 论文没有做任何医学数据验证。半透明体素的 reactive mask 是作者点名的未解项。

所以我的判断是：方法学强烈推荐，DVR 落地有条件推荐。先拿四类配准约定去核对现有管线 （零成本、纯正确性），再把 α 加入监控；等这两步做完，再决定要不要训模型。

部署前自检清单

研究机会 如果要把它用于医学 DVR，我会先问三个问题：半透明层的 MV 怎么定义？能否用 per-pixel 自适应 λT 替代全局权重？在真实 CT 体渲染噪声下，α 的诊断含义还成立吗？这三个都不是这篇论文能回答的。
08

结论：三条可执行判断

读论文的收益，最终要落成可执行的判断。

  1. 时序损失优化的是“变化匹配”，不是“信息吸收”。配准正确时，复制历史在时序项上几乎免费； 网络没有义务继续采样。要判断它有没有在学，必须看 α，而不是看画面稳不稳。
  2. 配准是方法的一部分，不是实现细节。四类错误能把冻结藏得几乎看不见；λT=0 时 完整配准与原始约定只差 0.03 dB。先修配准，再调权重。
  3. 指标要成组看。PSNR、静态 STD、tPSNR 都可能奖励冻结；JOD/ColorVideoVDP 与 α 一起， 才能区分“收敛”与“停止累积”。
核心结论

这篇论文把“时序一致性损失”从抗闪烁的正则项，变成了一个可能让模型停止累积的激励错配； 它给出的不是新网络，而是一套诊断工具：copy cost、α、两套晶格、四类配准错误。
