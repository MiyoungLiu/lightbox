论文精读——一套高斯，四十一套显影把传递函数变成可编辑输入

医学体渲染的外观由传递函数决定：同一个 CT，换一套区域曲线，骨、血管与软组织的可见性就完全改变。 图像训练的 Gaussian 代理通常把一套曲线烘进颜色与不透明度，换预设就要重建。FactorSplat 把传递函数作为推理时输入： 每个高斯保留一份局部材质描述子，物理查找给出作者编辑的直接响应，共享编码器与低秩因子补上渲染器的残差。 七个 CT/MR 扫描、每例 41 套条件，一个检查点在 1600² 下平均 524 FPS，切换 1.17 ms。

结论速览：把“换外观”从重建改成条件

一页速览。按“问题 → 机制 → 数字 → 边界”排列。

  1. 传递函数不是类别标签。一套预设是每个分区一条 intensity→RGBA 曲线；同一强度在不同分区可以有不同颜色与不透明度。 把预设编码成 one-hot 或 embedding，遇到训练集外的曲线只能退回最近邻，曲线形状本身的信息被丢掉。
  2. 做法是“物理查找 + 学习残差”。每个高斯在初始化时固定 3×3×3 邻域的最多 27 个 (区域, 强度) 样本； di(T)=Σk wik δrT 给出作者编辑的直接响应， 共享 Deep Sets 编码器输出 8 维码，逐高斯低秩因子再修正 DC 颜色与不透明度。几何与方向 SH 完全不随 T 变。
  3. 质量与编辑保真同时提升。相对 region-aware VEG，七个扫描平均 PSNR 提升 +1.45 / +1.52 / +1.10 / +1.41 dB（validation / interpolation / composition / OOD）， 24/28 个场景-划分比较获胜；changed-region ΔTF 在 19/28 更低，四个划分的均值都更低。
  4. 吞吐与训练成本。B200、1600²：缓存快速渲染器平均 524 FPS（VEG 144）， TF 切换 1.17 ms；训练 9.8 min/扫描（VEG 43.8）。 一个检查点覆盖 17 个评估 TF，而专职模型每个 TF 一个。
  5. 边界。一例一个代理，仍需逐扫描优化；OOD 新操作上专职模型平均高 5.2 dB； 局部条件无法响应全局光照变化；描述子在几何优化中固定，可能失配；代码未公开。

01

背景：传递函数是体渲染的“光学规则”，不是后处理滤镜

医学 DVR 的外观由体素如何发光、遮挡与透射决定。换一套区域曲线，解剖可见性会改变，几何却没有变。

在 CT 中，每个体素有一个校准后的 HU 值；在 MR 中，则是渲染器归一化后的标量。传递函数把强度映射为颜色与不透明度： RT(m,h)=(ρT(m,h),aT(m,h))。 这里 m 是分区索引，h 是强度。分区不是可有可无的：骨与增强血管在 HU 上可能重叠， 同一强度落在不同解剖区域，作者希望给它不同的颜色与不透明度。临床渲染器因此为每个分割区域维护一条独立曲线， 一套预设就是这组曲线的集合[9]。

这带来一个容易被低估的后果：传递函数不只改变“看起来什么颜色”，还改变哪些结构参与遮挡、哪些结构被透过。 在 cinematic rendering 的路径追踪里，不透明度参与光照积分；把骨调透明，后面的血管才会显影。 因此“换一个窗宽窗位”与“换一套区域曲线”不是同一类操作，后者是光学规则的整体替换。

N-DGS 的恒等下限（identity floor）说明了“完全不给 TF 输入”会发生什么：把 24 套训练预设的图像混在一起训练一个代理， 但不告诉它当前是哪一套。CT 上 changed-region ΔTF 为 3.60 / 6.49 / 8.96 / 17.74 ×10⁻² （validation / interpolation / composition / OOD），PSNR 只有 31.11 / 27.88 / 25.50 / 21.11 dB。 它不是“模型不够大”，而是输入里没有区分外观的条件：同一几何对应多套互相冲突的颜色，网络只能给出条件平均。

专职模型把这件事做到另一个极端：每套目标 TF 单独拟合 48 个视图，PSNR 30.70–31.94 dB（CT 均值）， 代价是每套一个检查点。VEG 是更接近的基线：它已经做到推理时查表、换 TF 不重训；本文把每个高斯的一个标量 换成局部材质分布，并用学习残差补电影级渲染器的图像空间效应。这个定位很重要——FactorSplat 不是第一个 “可换 TF 的高斯代理”，它的增量在局部条件与残差分解[1][4]。

论文把剩下的难点拆成三条，后文的设计逐条对应：

  • 函数值输入。预设不是离散类别，而是一族曲线；训练集外的曲线形状必须能进入模型，不能只查最近邻 embedding。
  • 空间异质。同一条曲线编辑，对不同位置的高斯影响不同；影响取决于该高斯覆盖了哪些区域、哪些强度。
  • 覆盖保持。训练与致密化必须让“在其他预设下才显影”的结构仍然存在；否则换到那套预设时，几何已经被剪掉。
先纠正一个常见误读 VEG 并不是“把 TF 烘进颜色”的反例；它已经支持推理时换 TF。FactorSplat 的增量是 局部材质分布 + 学习残差 + 可见性门，而不是“第一个可换 TF 的高斯代理”。把基线说弱，会误判这篇的实际贡献。

每个高斯在初始化时采样自己的 3×3×3 邻域。第 k 个有效样本给出分区 mik、强度箱 bik，以及一个非负权重 wik，权重和为 1。权重来自初始化高斯的足迹：

式 2 · 描述子权重 wik ∝ exp( −½ (xik−μi)T Σi−1 (xik−μi) ),    Σk wik = 1 (μi,Σi) 是初始化时的中心与协方差，xik 是体素中心。 这个权重让描述子具备尺度感知：小于体素的高斯集中在自己覆盖的材质上，较大的高斯则对足迹内的材质做积分。

物理查找是该高斯所有样本上 δrT 的加权平均。它回答的是“作者这套曲线， 在这个高斯覆盖的局部材质上，平均改了什么”。这一步没有可学习参数，因而对训练集外的曲线也有定义。

式 3 · 物理查找 di(T) = Σk=1Ki wik δrT(mik,bik)   ∈  R3 × R Ki≤27 是有效样本数；没有有效样本时 di=0。 分区索引只用于选曲线：把曲线轴与分区标识一起置换，查找结果不变。

学习分支不是直接在图像上回归，而是先把每个样本的 RGBA 变化嵌入一个共享响应基，再按同一组权重池化。 这是 Deep Sets 的置换不变结构[5]；先编码再池化，避免不同局部编辑在平均时相互抵消。 例如骨曲线的改动只进入描述子里包含骨的高斯，软组织改动则走自己的支撑集。

式 4 · 共享函数编码器 φη(v) = W2 ReLU(W1v),   W1∈RH×4, W2∈Rr×H
zi,T = Σk wik φη(δrT(mik,bik)) ∈ Rr H=64，r=8；MLP 无偏置，且在 T0 处输入为零， 因此 zi,T0=0。每次切换只在 M×B 的表上评估一次， 再用 packed gather 给所有高斯取码。

每个高斯带一组低秩因子，把 8 维码翻译成 DC 颜色残差与不透明度 logit 残差。颜色分支有 tanh 限幅； 不透明度分支只在作者确实改了 alpha 时启用，避免纯颜色编辑意外改变可见性。

二值可见性门是参数无关的。对每个高斯，先把“相对基准预设被移除的区域”在它的描述子上的质量加起来： ηi(T)=Σm,b pi(m,b) rT(m)， 其中 rT(m)=vT0(m)[1−vT(m)]。 质量达到一半就整体移除；没有描述子支撑的高斯默认保留。门乘在 sigmoid 之后，被门掉的高斯不透明度严格为 0。

训练时的三个约束

外观条件只有共享几何已经覆盖了“以后会被显影的结构”时才有意义。论文因此在初始化时使用预设中性的网格， 覆盖所有分割结构的并集，包括在基准预设 T0 下完全透明的结构。 训练用混合预设的 batch stream，每个训练帧带自己的 TF；共享 anchor 相机让同一视角下出现成对的外观变化， 逐预设相机补足视角覆盖。

剪枝也必须改。标准 3DGS 用基础不透明度 σ(oi) 判断是否保留； 某个高斯在一套预设下几乎透明，在另一套下可能正是关键结构。论文把分数换成 κi=maxT∈Ttrain ᾱi(T)： 只要在任意一套训练预设下可见，就保留。相机相关的 siview 不计入这个分数， 几何与屏幕尺寸的剪枝标准照旧。

训练目标就是条件渲染后的光度损失，λs=0.2；没有额外的 TF 分类损失， 也没有对 di 或 zi 的监督。 所有外观参数与基础高斯联合优化，梯度穿过与测试时相同的合成路径。

设计要点 两条分支不是“可解释 + 黑盒”的堆叠，而是分工：查找负责“作者确实改了这个区域”，残差负责“电影级渲染器还会怎样改变图像”。 消融里去掉查找掉得最多，说明这个锚不能由残差替代。
03

核心机制：四个设计各自回答一个问题

完整模型的数字之外，消融给出的失败模式更有信息：哪一项是锚，哪一项只影响分布外，哪一项只在“移除材质”时起作用。

局部描述子：同一条曲线，对不同高斯不是同一件事

一个高斯可能覆盖骨与软组织的交界，另一个完全落在血管内。同一条“把骨调亮”的曲线，对前者只影响一部分支撑， 对后者几乎无影响。用单个标量或单个分区标签概括，都会把这种异质性压平。FactorSplat 保留最多 27 个 (区域, 强度) 样本及其权重，让每个高斯按自己的材质组成响应。

先编码再池化是另一个关键。若先把局部 RGBA 变化平均，再送进编码器，两个方向相反、幅度相近的编辑可能相互抵消； 先对每个样本编码，再做加权和，响应基保留了个体编辑的方向。置换不变性保证样本顺序不影响结果， 这也是 Deep Sets 的标准性质[5]。

描述子在初始化时固定，而不是在每次切换时从优化后的中心重新分区。作者的理由是：几何优化后中心会移动， 重新分区会让材质关联漂移；固定描述子相当于给每个高斯保留一份“出生地”的材质指纹。代价是中心移动较大时， 指纹可能与新位置失配——这一点在 §7 的边界里展开。

物理查找：没有它，残差会失去锚

查找分支只做一件事：把作者曲线在该高斯局部支撑上的平均变化算出来。它没有参数，因此对训练集外的曲线也有定义； 它也不依赖图像，因此不会把某一套训练预设的渲染风格误当成曲线本身。消融里去掉查找，掉幅最大： heart 的 composition 从 28.68 降到 26.11 dB（−2.57 dB）， vascular 从 32.59 降到 29.94 dB（−2.65 dB）。这说明学习残差并不能从图像里反推出 “作者到底改了哪条曲线”的全局方向。

学习残差：补的是渲染器，不是曲线

电影级渲染器的图像空间效应不完全是局部 RGBA 的线性函数：遮蔽、散射、色调映射与路径追踪的采样都会让 “同一局部颜色变化”在不同解剖位置上呈现不同结果。低秩残差分支用共享编码器提取曲线变化的响应基， 再用逐高斯因子把它投影到 DC 颜色与 opacity logit。它的参数量是 4Nr， 随高斯数线性增长，与预设数无关。

去掉残差，八个 PSNR 列全部下降：heart 的 validation 30.79→30.16、OOD 23.77→23.22； vascular 的 validation 34.20→33.70、OOD 30.88→29.28。掉幅不如去掉查找那么剧烈，但它覆盖了查找无法表达的 图像空间修正，尤其是在新操作上。

函数输入：平均分差不多，分布外差很多

把函数码换成“最近训练预设的 embedding”，是一个很强的对照。它在 vascular 的 validation 与 composition 上 甚至略好：34.30 / 33.07 dB，对比完整模型的 34.20 / 32.59 dB；但在 OOD 上掉 2.84 dB（30.88→28.04）。 这个结果说明：如果目标曲线离训练集很近，离散 embedding 足够；一旦曲线形状是训练集里没有的组合， 最近邻就无法表达“这条曲线在这个局部支撑上到底改了什么”。函数输入的价值主要在分布外，而不是均值。

可见性门与覆盖剪枝：一个负责“移除”，一个负责“别提前移除”

可见性门是作者显式给的二值操作：某分区在这套预设下不可见。论文不把它交给网络学，而是按局部描述子里 被移除区域的质量是否达到一半，整颗高斯乘 0 或 1。去掉门，validation / interpolation / composition 几乎不变， 因为这三类条件大多不涉及整块移除；OOD 上 PSNR 掉 0.32 / 0.52 dB，changed-region ΔTF 从 9.64 升到 10.87、 从 4.54 升到 5.01（×10⁻²）。门的作用集中在“目标隔离、遮挡物抑制”这类操作。

覆盖感知剪枝解决的是相反方向的风险：如果按基准预设的不透明度剪枝，某颗在 T0 下透明、但在另一套预设下关键的高斯会被提前删掉。用 maxT ᾱi(T) 作为分数，等价于“只要任何一套训练预设需要它，就保留”。这是多预设共享几何的必要条件，不是可选的工程优化。

工程细节：数据、训练、渲染三本账

能复算的写清楚，不能复算的标估算。论文没有给显存峰值，也没有给端到端时延。

数据与划分：七例，每例 41 套条件

七个扫描来自五个 CT（heart、vascular、intestine、lower、kneejoint）与两个 MR（nose、hand）。 每个扫描有 3–17 条区域曲线，因此 M 随解剖部位变化。每例共 41 套条件， 划分为 24 套训练、4 套验证、4 套插值、4 套未见组合、5 套分布外。所有方法都只能看到 24 套训练条件； 验证、插值、组合、OOD 都不参与拟合。

论文没有给数据集名称、采集站点、扫描仪型号、层厚/分辨率或伦理批号；七个扫描也不是公开基准。 这会影响复现与外部效度，后面单独讨论。

训练：30k 迭代，一例一个代理

所有方法都用 30,000 次迭代；条件模型共享 24 套训练预设。FactorSplat 用 r=8、 H=64、B=64、K=27， 并采用 Mip-Splatting 的 3D 滤波[6]。外观尺度固定为 λLc=1、λLα=4、λRc=0.25、λRα=4； 查找增益 gc、gα 可学习。损失是 L1 + SSIM，λs=0.2。

七例平均训练时间 9.8 min/扫描（CT 10.5、MR 8.3），VEG 为 43.8 min（CT 44.3、MR 42.6）。 一个 FactorSplat 检查点覆盖该扫描的全部 17 个评估 TF；专职 N-DGS 每个目标 TF 一个检查点。 论文把 17 个专职模型的训练成本合计为 88.1 min/扫描，约为共享模型的 9 倍。

口径提醒：Table 1 的 specialist 训练列写 92.8 min（CT）/ 76.4 min（MR），均值 88.1；§4.4 说这是 “17× 单个固定预设的训练时间”。按字面折算，单个专职模型约 5.2 min； 若把 92.8 读成单个模型，17 个就是 1577.6 min，与 88.1 矛盾。 表格没有明说这一列是“单个模型”还是“17 个合计”，这是复现时首先要问清的口径。

渲染：524 FPS 与 1.17 ms 各自是什么

计时在 B200、1965 MHz、1600² 下进行。每个方法渲染相同的 8 个验证视图，5 次 warm-up，20 次 CUDA event； FPS 取平均帧时间的倒数。FactorSplat 的 FPS 用快速渲染器，PSNR 用质量渲染器， 两者可以产生不同图像；论文明确把“部署吞吐”和“重建质量”分开报告。质量指标覆盖全部 680 个 held-out 视图 （17 个 TF × 40 个相机）。

TF 切换的 1.17 ms 是外观缓存构建时间：共享编码器在 M×B 表上评估一次，所有高斯 gather 出 8 维码，再更新并缓存 DC 颜色与不透明度。它每次切换只付一次， 相机移动不重复付。这个数字不包含相机移动本身、数据加载、图像保存与评分。

表示开销：因子矩阵可按公式估算

每个高斯增加 4r 个因子；编码器只有 H(4+r) 个权重， 再加 4 个查找增益。以 heart 的 278.6k 个高斯、r=8 为例， 因子矩阵是 4×278,600×8≈8.92M 个浮点数：fp32 约 35.7 MB， fp16 约 17.8 MB。这只是因子矩阵，不含基础高斯属性、方向 SH 与最多 NK 个持久描述子样本；论文没有报告总显存或模型体积。

批判性边界：作者没展开的六个风险

作者自述的局限是起点，不是全部。以下几条按“影响落地”的顺序排列。

  1. 一例一个代理，没有跨患者泛化。每个扫描单独优化 9.8 min；七个扫描就是七次拟合。 论文把 feed-forward 预测共享几何与条件外观列为未来工作，说明当前版本仍不是“训练一次，服务所有患者”。 对临床部署，这意味着每来一个新扫描都要重新优化，且需要该扫描的多预设参考图像。
  2. OOD 仍输给专职模型。五个 OOD 条件上，专职模型平均高 5.2 dB；VEG 在 heart OOD 与若干 kneejoint 划分上更好。组合条件四胜一平两负。函数输入改善了分布外，但没有消除“直接对目标 TF 拟合”的优势。 新操作如果超出训练 bank 的覆盖，仍需要扩 bank 或重新拟合。
  3. 局部条件的物理上限。作者明确说：局部条件把响应绑在高斯覆盖的材质上，因此无法响应全局光照变化； 编辑若改变整体照明，而高斯的支撑没有被编辑覆盖，它的码不会变。描述子在初始化时固定，中心移动较大时可能失配； 可见性门整颗移除高斯，而不是在体素边界裁剪，薄结构可能出现整颗消失或留下空洞。
  4. 数据与评测的外部效度。论文没有给数据集名称、采集站点、扫描仪、层厚/分辨率或伦理批号； 七个扫描不是公开基准。真值来自对同一体数据与分割掩膜的路径追踪，分割质量与体数据质量被当作既定条件。 指标只有全帧 PSNR 与 changed-region ΔTF，没有感知指标、读者研究或临床任务评估。ethics statement 明确说 这不是临床验证系统，TF 编辑会改变解剖可见性。
  5. 计时口径不等于端到端。FPS 用快速渲染器，PSNR 用质量渲染器；1.17 ms 只是 TF 缓存构建， 不含相机移动、数据加载、图像保存与评分；硬件是 B200，没有显存峰值、CPU/移动端或 Web 端数据。 对“临床工作站能否实时”这个问题，论文没有回答。
  6. 训练成本列的口径冲突。Table 1 的 specialist 训练列与 §4.4 的“17× 单个固定预设”按字面不能同时成立： 92.8 min（CT）/ 76.4 min（MR）的均值是 88.1；若这是单个模型，17 个应是 1577.6 min；若这是 17 个合计， 单个约 5.2 min。表格没有写明。这个歧义不影响“共享模型更省”的方向，但影响倍数与复现预算。

复现风险

论文只给项目页，没有公开代码仓库；截至 2026-11-09 未检索到公开实现。描述子的存储格式、clone/split 时的继承细节、 剪枝掩码如何与因子行对齐、VEG 数值稳定性修复的具体实现，都只能从正文推断。VEG 基线还修了一个 released 版本的 数值 bug：当 shininess 在 (0,1) 时，|nTh|s 在零点的导数奇异， 会产生非有限梯度并中断训练。复现者若直接用未修版本，结果不可比。

VEG 的 native-quantized 导出版本损失 0.15 / 0.12 / 0.10 / 0.05 dB （validation / interpolation / composition / OOD）；FactorSplat 没有报告量化或导出路径。 这不代表 FactorSplat 不能量化，只代表论文没有给证据。

07

带走：五条可执行结论

每条不超过两行；括号内是依据。

  1. 把传递函数当函数输入，不要当类别。用作者曲线做锚点（物理查找），学习分支只补渲染器残差； 离散 embedding 在近邻条件够用，在 OOD 会掉 2.84 dB。
  2. 多预设共享几何的前提是覆盖。混合预设训练 + maxT ᾱi(T) 剪枝；否则被其他预设揭示的结构会在基准预设下被提前删掉。
  3. 交互预算按“切换”而不是“每帧”。TF 条件属性缓存一次（1.17 ms），相机运动复用； 不要在每个视角重复编码曲线。
  4. 评测必须成对。changed-region ΔTF 与全帧 PSNR 一起看；heart 上 PSNR 更高但 VEG 的编辑差分更准， 单指标会误判。
  5. 部署判断看预设数量。K=1 用专职模型更便宜；K≥2 共享模型开始省；K 越大，41 套条件共用一个检查点的优势越明显。
核心结论

FactorSplat 把“换一套显影”拆成两件事：作者曲线改变什么（物理查找），以及电影级渲染器还会怎样改变图像（学习残差）。 几何与方向外观共享，外观因子随预设连续变化。它因此能用一例一个检查点覆盖 41 套条件，并在 1600² 下保持 524 FPS； 代价是逐扫描优化、OOD 仍不如专职模型，以及一个尚未公开的实现。
