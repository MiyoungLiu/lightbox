神经网络全景：从单个神经元到 Transformer

写给完全没有接触过深度学习的人。读完之后，你能亲手算一遍反向传播，也会明白 CNN、ResNet、Transformer 各自是为了补哪个短板才出现的。

阅读前提：会四则运算，知道“函数”是什么。
不需要微积分，不需要线性代数，不需要写代码。
本页所有数字都能用计算器复核，五段手算共用同一套记号。

如果你只有三分钟

  1. 神经网络是一个带旋钮的函数。旋钮就是权重和偏置，训练就是把这些旋钮拧到合适的位置。
  2. 拧的方向由梯度决定。梯度告诉你“往哪边拧会让误差变小”，沿它反方向走一步，就是一次参数更新。
  3. CNN、ResNet、Transformer 不是越新越好，它们分别补上了“参数量爆炸”“层加不深”“卷积看不远”这三个具体的坑。

一、神经元在算什么

这一节回答一个问题：一个神经元接收几个数，吐出什么。答案只有两步运算。

先把一件事说清楚：神经网络不是对大脑的复刻，它是一个普通的数学函数。给一组输入，它算出一个输出。整个深度学习做的事情，就是让这个函数在训练数据上算出正确的输出。

最小的计算单元叫神经元（Neuron）。它做两件事：先加权求和，再过一次非线性。

加权求和weighted sum

假设一个神经元接收两个输入 x1、x2，它给每个输入配一个权重（Weight）w，再加一个偏置（Bias）b：

z = w1·x1 + w2·x2 + b

权重表示“这个输入有多重要”，偏置表示“这个神经元天生偏向哪一边”。这两个量都是可调的数字，训练调的就是它们。

过非线性activation

把 z 送进激活函数（Activation Function），得到神经元的输出 a。最常用的是 ReLU（Rectified Linear Unit）：负数一律压成零，正数原样放过。

a = ReLU(z) = max(0, z)

为什么必须有非线性why activation

如果去掉激活函数，神经元就只剩一次线性变换。而线性变换有个致命性质：叠多少层，都还是一层。

关键结论

非线性不是锦上添花，它是“深度”能成立的前提。没有激活函数，网络再深也只是把输入乘了一个大矩阵，表达能力停在单层线性模型。

这里容易错

Sigmoid 的两端不是“学得慢”，是导数真的趋近于零。梯度的连乘里只要有一项接近零，整条链的梯度都会被拉到接近零。这是梯度消失（Vanishing Gradient）的直接来源，也是 ReLU 后来取代 Sigmoid 的主要原因。

从一个到一层from neuron to layer

把一排神经元并排放，就是层（Layer）。真正的实现不会逐个算，而是把输入堆成向量、把权重堆成矩阵，一次乘完：

z(4×1) = W(4×3) · x(3×1) + b(4×1)

一个 3 维输入，经过 4 个神经元，得到一个 4 维输出。矩阵里的第 i 行就是第 i 个神经元的权重。

把矩阵乘法写成一次批量运算，是 GPU 能把这件事做得极快的全部原因。这也解释了为什么所有框架的第一步都是把数据变成张量（Tensor），也就是多维数组。

二、损失：把“错得多离谱”变成一个数

这一节回答：怎么用一个标量描述“当前参数有多差”。

网络输出一个数，我们希望它接近正确答案。要调参数，先得把“差多远”变成一个可以求导的量，这个量叫损失（Loss）。

回归任务最常用的是均方误差（Mean Squared Error, MSE）：对每个样本求预测与真值之差，平方，再取平均。

L = 1n · Σi (ŷi − yi)2

为什么用平方，而不是直接取差值的平均？两个原因。一是差值有正有负，直接平均会互相抵消，一个偏大 1.0、一个偏小 1.0 会被算成完全正确。二是平方会放大较大的错误，让模型优先修正错得最狠的样本。

如果第 2 个样本的预测是 0.00 而不是 0.40，误差从 0.40 变成 1.00，平方后从 0.16 变成 1.00，一项就让 MSE 涨到 0.35。平方把这一项放大了六倍多，模型会被迫先修它。这就是“优先修正错得最狠的样本”的实际含义。

分类任务用的不是 MSE

分类通常用交叉熵（Cross-Entropy）。它衡量两个概率分布的差异，配合 softmax 使用，和 MSE 相比在概率输出上的梯度性质更好。选哪个取决于任务，不取决于新旧。它的完整推导不在本页展开，记住这一条判断依据就够了。

三、训练是怎么发生的

这一节从一维的“蒙眼下山”讲到多层的反向传播，中间有一个可以动手操作的仪表。

一维热身descent in one dimension

先把参数缩减到一个。假设损失只依赖一个参数 w，曲线像一个碗，碗底就是我们要找的位置。问题是：站在碗的某一侧，你看不见碗底在哪，只能摸到脚下的坡度。

坡度就是导数，多个参数时推广为梯度（Gradient）。它告诉你两件事：往哪边是上坡，坡有多陡。既然要下山，就往反方向走。

w ← w − η · ∂L∂w

η 是学习率（Learning Rate），表示每步走多远。这一行公式就是整个深度学习最核心的动作，后面所有复杂的网络，训练时做的都是这一行。

在 L(w) = (w − 3)² 上，收敛的条件是 η < 1。这个临界值和曲线的曲率有关：曲率越大，能容忍的学习率越小。真实网络里每一层的曲率都不一样，这也是为什么实践中要用学习率调度，而不是从头到尾一个值。

多参数与反向传播backpropagation

真实网络有上百万个参数，损失对每一个参数各有一个偏导，这些偏导排成向量就是梯度。问题是：逐个用数值方法去试（扰动一个参数、重新算损失）代价高到不可行，一次完整计算就要前向跑上百万遍。

反向传播（Backpropagation）解决的正是这个代价问题。它的数学内核是链式法则：复合函数的导数等于各层局部导数连乘。

∂L∂w1 = ∂L∂a · ∂a∂z · ∂z∂w1

关键在于运算顺序。前向传播时已经算过的那些中间值（每一层的 z 和 a），反向时可以直接复用，不必重算。所以从损失往回走一遍，就能一次性拿到所有参数的梯度，代价和前向传播同一量级。

下面这个 2-2-1 网络把整件事完整走一遍：两个输入、两个隐藏神经元、一个输出。每一行都可以拿计算器复核。

w₂ = [0.6, −0.4]　　 b₂ = 0.2　　 真值 y = 1.0　　 学习率 η = 0.1

把这一步重复上万次，每次换一批数据、算一次前向、回传一次梯度、更新一次参数。所谓“训练模型”，字面意思就是这个循环。GPT 和自编码器用的是同一套流程，区别只在网络结构和损失函数的形状。

同样的三十行代码the same thing in numpy

下面这段代码和手算 4 是同一个网络、同一组数字。跑出来的梯度应当逐位等于手算结果，误差在浮点精度内。

import numpy as np

x  = np.array([1.0, 2.0])
W1 = np.array([[0.5, -0.2],
               [0.3,  0.8]])
b1 = np.array([0.1, -0.1])
w2 = np.array([0.6, -0.4])
b2 = 0.2
y  = 1.0
lr = 0.1

# forward
z1    = W1 @ x + b1
a1    = np.maximum(0.0, z1)      # ReLU
z2    = w2 @ a1 + b2
y_hat = z2
loss  = (y_hat - y) ** 2

# backward: dLoss/dy_hat -> dLoss/dz2 -> dLoss/da1 -> dLoss/dz1
g   = 2.0 * (y_hat - y)          # dLoss/dy_hat
dw2 = g * a1
db2 = g
da1 = g * w2
dz1 = da1 * (z1 > 0)             # ReLU gradient: pass where z1 > 0
dW1 = np.outer(dz1, x)
db1 = dz1

# update
w2 -= lr * dw2
b2 -= lr * db2
W1 -= lr * dW1
b1 -= lr * db1

PyTorch 里这段反向传播不用手写。把 requires_grad=True 打开，前面的计算照常进行，然后调一次 loss.backward()，所有参数的 .grad 就已经填好了。它做的和上面 g / dw2 / da1 / dz1 那几行完全一样，只是自动帮你把链式法则应用到整张计算图上。

四、架构为什么不断进化

这一节不列模型清单，只讲每一次换架构，是为了补上一个具体的缺陷。

全连接处理图像的三个硬伤why not MLP

最朴素的网络叫多层感知机（Multilayer Perceptron, MLP），就是若干全连接层叠起来。它在表格数据上能用，直接拿来处理图像会立刻撞墙。

先算参数量。一张 224×224 的彩色图展开成向量是 224 × 224 × 3 = 150,528 个输入。接一个只有 1000 个神经元的隐藏层：

而一个 LeNet 级别的卷积网络处理同样的输入，全部权重加起来不到六万。差了三个数量级。

另外两个硬伤同样致命。展开会把相邻像素的空间关系彻底打散，网络再也分不清“上”和“下”。同时全连接对位置毫无敏感性：把一只猫平移十个像素，对网络来说这是一张全新的图，一切要重学。

卷积：局部连接加权重共享CNN

卷积神经网络（Convolutional Neural Network, CNN）用两个约束同时解决上面三个问题。

局部连接：每个输出只连线到输入的一个小窗口（比如 3×3），参数量从“全图乘以所有神经元”降到“窗口大小乘以通道数”。

权重共享：同一个 3×3 的核在整张图上滑动，每一处都用同一组权重。这既把参数量压到常数级，又让网络天然具备平移等变性：猫在左上角和右下角，触发的是同一个检测器。

感受野receptive field

感受野是一个神经元在原始输入上能看到多大范围。单个 3×3 卷积看三格，但把三层叠起来，第三层的每个输出就能看到 7 × 7 的范围，因为每一层都在上一层的窗口基础上再扩一圈。

关键在于代价：用三层 3×3 达到 7 × 7 的感受野，和直接用一层 7×7，参数量差很多。设通道数为 C：

方案参数量C = 64 时
一层 7×749·C²200,704
三层 3×327·C²110,592

大约省掉百分之四十五的权重，同时还多插入了两次 ReLU，非线性更强。这就是 VGG 用三个 3×3 替代一个 7×7 的原因，也是现代网络的默认做法。

更深带来的新问题：退化degradation

既然层叠能扩大感受野，那是不是越深越好？不是。实验里出现了一个反直觉的现象：给一个已经收敛的网络再接几层，训练损失反而变大。

注意这不是过拟合。过拟合是训练损失小、测试损失大；退化是训练损失本身都压不下去。原因是纯堆叠让优化变难了：恒等映射（原样输出输入）对多层非线性组合来说反而不好学，而它本该是最容易的退路。

残差连接（Residual Connection）直接把这个退路铺好：

y = F(x) + x

网络不再需要学习“恒等映射”，只需要学习“在输入基础上的修正量” F(x)。如果这一层没用，把 F(x) 学成零就退化成恒等，至少不比原来差。求导时：

∂L∂x = ∂L∂y · (1 + ∂F∂x)

那个 1 意味着梯度总有一条不经过任何非线性层的直达通道。即使 ∂F/∂x 因为连乘变得很小，梯度也不会被完全掐断。ResNet 靠这个把网络从二十层推到一百五十二层，后来的一千层版本也成立。

卷积看不远，于是有了注意力attention

卷积的视野是局部的，要它看到全图就得堆很多层。能不能让每个位置直接看到所有其他位置？能，代价是要用注意力（Attention）替换卷积。

注意力机制的直觉是查字典。你手里有一个查询 Q（Query，你想找什么），每一条信息有一个键 K（Key，它能提供什么），和一份内容 V（Value，它实际是什么）。用 Q 和每个 K 算相似度，按相似度把所有 V 加权求和：

Attention(Q, K, V) = softmax(QKT√dk) · V

权重是算出来的，不是人设的。一句话里“它”指代谁，由“它”的查询向量和各个名词的键向量算出的相似度决定。这正是卷积做不到的事：卷积的权重由位置决定，注意力的权重由内容决定。

代价要一起说

n 个位置两两算相似度，计算量随 n² 增长。序列翻倍，算力要涨四倍。这是 Transformer 处理高分辨率图像和长文本时的实际瓶颈，也是后来一堆线性注意力、状态空间模型（Mamba）要解决的问题。

Transformer 与位置编码positional encoding

把注意力和全连接层交替堆起来，就是 Transformer。它摆脱了循环网络必须逐字处理的串行依赖，整段序列可以并行算。

但注意力有一个副作用：它对输入顺序完全不敏感。把一句话的词打乱，每个词算出的注意力权重集合是一样的，因为相似度只看内容不看位置。而对语言和图像来说，顺序本身就是信息。

解决办法是位置编码（Positional Encoding）：给每个位置额外的向量，加到输入的表示上，让模型能区分“第一个词”和“第五个词”。这一步很小，但没有它，Transformer 就只是一个无序的词袋。

演化时间轴timeline

把上面这些串起来，就是一条“每一代补一个坑”的线索。

年份模型补的什么坑

看这条线的正确方式

新架构不是把旧架构淘汰掉。CNN 仍然是图像复原的主流 backbone，ResNet 的残差连接被几乎每个现代网络沿用，注意力则被塞进了 CNN 里当成模块用。所谓演进，更多是“把上一代的零件拆下来装到新的结构里”。

收尾：五个常见误区

这五条如果一开始就搞清楚，能省掉很多弯路。

  1. “局部极小值是训练的死穴。”

    在几十万维的参数空间里，真正的局部极小值比鞍点稀少得多，而鞍点是可以走出来的。实践中的问题很少是“卡在局部极小”，更常见的是学习率没调好和数据有问题。

  2. “参数越多效果越好。”

    参数量要和数据量匹配。数据不够而参数极多，模型会去记训练集的噪声，测试表现反而更差，也就是过拟合。大模型之所以能用，前提是有海量数据。

  3. “没有大算力就入不了门。”

    跑通一个手写数字识别的小卷积网络，笔记本 CPU 几分钟就够，也不需要显卡。理解原理和训练出一个可用的模型，是两件要求完全不同的事。

  4. “数学不熟就学不了。”

    起步只需要三样东西：能看懂导数表示变化率、会算矩阵乘法、知道均值和方差是什么意思。其余的可以边做边补，而且缺哪块补哪块的效率更高。

  5. “从 Transformer 开始学最快。”

    Transformer 是为了解决卷积看不远、循环网络不能并行这两个具体问题才出现的。跳过前两代直接看它，会不明白它为什么长这个样子，也不容易判断它的代价在哪。

一页速记

神经元是加权求和 + 非线性。损失把误差压成一个数。梯度指出变差最快的方向，所以往反方向走。反向传播是链式法则的高效实现，代价与前向同量级。CNN 用局部连接与权重共享对抗参数量，ResNet 用残差对抗退化，Attention 用内容相似度对抗局部视野。每一代都在补上一代的一个坑。
